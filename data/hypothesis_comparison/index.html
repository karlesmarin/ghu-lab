Importar y descargar

La ficha exporta selección y resultados en JSON, cada figura en SVG y los 15 intervalos observados en CSV. El JSON incluye covarianza y procedencia. Importar ese JSON restaura selecciones válidas; incorporar otro dataset requiere un adaptador auditado, no basta cambiar el archivo. El ZIP del catálogo incluye datos y scripts para repetir los cálculos.

Repetir desde la raíz del paquete descomprimido

python proof/verify_bundle.py
python data/hypothesis_comparison/build_visuals.py --check
python proof/hypothesis/certify.py --check

Requisitos: Python con NumPy, SciPy y SymPy, Node y Lean 4.27.0. El certificado reproduce las nueve referencias y verifica la covarianza publicada. El script build_visuals comprueba las muestras de las figuras sin sobrescribirlas.

Las cotas de la integral completa y del mínimo global siguen pendientes. Las tres cotas puntuales de derivadas no las sustituyen. La discrepancia aproximada del 7,4 % entre ajuste cuártico y tabla permanece abierta.
