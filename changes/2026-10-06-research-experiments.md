what
: Count a rung now builds its plot automatically. Candidate-seed curves and recurrence checks use the half-integral A4 grid; the published measured-mass fibre and budget comparisons are not transferred to that seed.
: Existing sections gain Maru–Nago SU(6), warped differential gauge running, a three-copy neutrino
  flavour construction, computed Majoron decay channels, RS gauge/baryon anomalies, thermal SU(3)
  with real PhaseTracer bounces, and complete Higgs scenarios evaluated with official HiggsTools
  datasets. Each experiment has a question, key indicators, interpretation, comparison snapshots,
  expandable numerical details, figure selection and a readable research summary export.

why
: A useful calculation must make its inputs, numerical stability and permitted conclusion visible
  together. The existing navigation already provides the right places for these questions.
  New external calculations record program and dataset versions and are rejected when their inputs
  do not match the current scenario. The static reference examples and browser calculations work
  offline; an optional local scientific engine handles new bounce and experimental-fit points.

so
: These are explicitly scoped model calculations. PMNS inputs are reconstructed, not predicted;
  finite-temperature nucleation uses an S3/T proxy, with precision sensitivity displayed; Higgs
  exclusion applies to the specified scalar scenario. Frozen Editions physically omit the local
  network bridge. Source tests, independent SciPy/Sage checks, real external runs and Chromium
  interaction tests accompany the new modules. No paper or archived checkpoint is revised.
