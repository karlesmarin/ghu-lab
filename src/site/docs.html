Gravity–gauge · 3D: a quick start

Open the panel, or choose Gravity & gauge · research → Gravity–gauge · 3D in the app menu. Its inputs belong to this panel and travel with its exported files and link.

  1. Start at p = 1.1. Compare the presets η = −0.9 and η = 0. The paired masses stay fixed, while the response and Wilson kinetic scale change.
  2. Move η (the kinetic deformation) and t (the source position). The table and both plots update immediately. The controls cover −0.99 ≤ η ≤ 4 and 0.12 ≤ t ≤ 0.98. Here η is a continuous parameter, separate from the boundary-condition sign used in the other panels.
  3. Choose the spectral-weight ratio or the kinetic function Z for the response surface. Its height is logarithmic. Drag to rotate; in select point mode, click the surface to set η and t. Shift-drag rotates in either mode.
  4. Focus a plot and use the arrow keys to turn it, the mouse wheel to adjust its relief, or double-click to reset the view. Reset restores the model and both views.
  5. Use the header's card, LaTeX and link buttons to save the current inputs, outputs and scope. Open the panel's how-to for help in place.

Read the comparison carefully. NN means a vanishing normal derivative at both ends; DD means a vanishing field at both ends. The tensor-NN and vector-DD massive towers are paired under the stated action and boundaries. The vector-NN control has different boundaries and its massive levels can move. The tensor zero mode has no vector-DD partner.

The first three paired masses are dimensionless Python/SciPy reference roots checked by an independent differential-equation calculation. The first massive vector-NN root is solved in the browser. The source response holds the four-dimensional gauge coupling fixed. The Wilson scale is a kinetic normalization; it is not a Higgs mass.

Scope. p = 1.1 admits the stated scalar-supported bulk background; p = 1 is a kinematic reference, with η = −0.99 recovering the minimal AdS gauge case. Boundary dynamics, scalar/radion stability, a complete Higgs potential and collider rates remain open. This is not experimental evidence for a graviton or a completed unified model.

The result card — what the two download buttons give you

Every panel has ⇩ card and ⇩ LaTeX in its header. The card is the only thing that leaves the tool, and it is deliberately more than a number: it carries the input you gave and the defaults the tool applied on your behalf, every value with its status, the certificates a referee needs to re-check a bound without this tool, and a provenance line.

The status column is the part worth learning. theorem is proved and names the statement; verified was checked against an independent implementation; measured is true of what was run and no more; and unknown is not computed, with the reason printed beside it. An unknown is a verdict, not a gap — a tool that returned a plausible number there would be worse than one that refuses, because you would have no way to tell.

The provenance line ends in a kernel fingerprint, a digest of the code that produced the numbers. It is the field to look at when two cards disagree: same input and same fingerprint with different numbers is a bug worth reporting, while a different fingerprint means the engine moved between the two runs and the change log says what moved. Without it those two situations look identical. Since September 2026 the tool refuses to build a card that cannot name its kernel.

Two conventions are not defaults but structure, and they matter more than any of the above.

  • The Wilson-line phase. The potential is written as a function of one phase α, and the period is fixed by the group data, not assumed: a period of Wilson line is a central gauge transformation up to Weyl, which is what makes the fundamental domain representation-dependent (Part III). Whether the half-domain is legal is a computed output of the selection section, never a setting.
  • The winding sum. Each term of the one-loop potential is Re Li₅(s e^{i c π α}), summed to a truncation that is an input and not a hidden constant: the terms fall as n⁻⁵, so the tail is bounded by the truncation you choose and the page can report it. The default is 600 windings.

The models the instrument holds

A group is data, not code. The kernel knows about weight lattices, parities and winding sums; it does not know what SU(7) is. Adding a group means adding a JSON document.

Glossary

α
The Wilson-line phase: the vacuum expectation value of the extra-dimensional gauge field, in units where a period is 1. It is the electroweak hierarchy, because 1/R₅ = 2m_W/α.
α_min
Where the one-loop potential is minimised. In this class of models it is an algebraic function of two moments of the bulk content, so it is computed rather than searched for.
bulk content
The list of representations living in the extra dimensions, each with its orbifold parities and a multiplicity. It is the input to everything on this site.
D, A₄
The second and fourth moments of the content, weighted by Wilson-line charge. 8D is always an odd integer, so the curvature at the symmetric point can never vanish and the electroweak verdict is always well defined.
parities
The signs a multiplet picks up at the orbifold fixed points, written (+,+), (+,−) and so on. They decide which components survive with a massless mode.
η (eta)
The boundary-condition sign η = η₀η₁. Part V shows it rides on an index alone, so it is invisible to the Higgs potential exactly on Part IV's vanishing class.
the anchor
A published computation the instrument recomputes at load and shows as a chip, so the tool declares whether it currently reproduces an outside number before it shows you any of its own.
the bill in eighths
The cost of an escape from the proton-decay obstruction, measured in the quantum of D. It is a ratio of integers, so no normalisation enters it.
the ceiling
An upper bound on 1/R₅ that holds for arbitrary bulk content, obtained as an integer program whose relaxation has a two-variable dual, enumerated exactly in rationals.

How to reproduce any of it without this tool

Nothing here needs the page. Each section's mathematics exists twice: once in the kernel the browser runs, and once in a Python or Sage script shipped with the paper it comes from, written independently. Where the two are compared, that is what the verified chip means.

  1. The papers' own scripts. Every released paper carries an ancillary archive on Zenodo with the scripts that produce its numbers, and they run without this repository.
  2. The instrument, offline. Save the app to disk and open it. It is one file with no external request in it; the build refuses to ship one that has any — no fetch, no dynamic import, no new Worker, no <script src>, no http(s) asset.
  3. The harnesses. python build/build_app.py rebuilds the page and then re-runs every check outside it, in node, against numbers produced elsewhere. A red build is not publishable, and the build says so rather than warning.

How to cite

Cite the paper, not the page. The papers have DOIs and are immutable; this site is living and says so on every paper page. If you need to cite the state of the tool as you used it, cite the frozen edition archived with the paper, which is byte-identical to the copy on Zenodo.
